# Formicrown legal and support pages

The game and store metadata link to these public documents:

- https://eclawbot.com/AiHankApps/anthill/privacy.html
- https://eclawbot.com/AiHankApps/anthill/support.html

These are standalone, parallel Traditional Chinese and English documents for the current 0.36.0 offline game. Both languages are always readable, including with JavaScript disabled; the language links jump to labelled sections. They deliberately do not load the EClaw portal, its account session, analytics or automatic language replacement. The approved policy text is the content source, rather than the portal translation dictionary. Existing global i18n syntax/reference checks still run unchanged.

The shared `policy.css` supports a two-column desktop layout and one-column mobile layout. Support email links open the user's mail app; these documents do not send mail, upload saves or contain forms.
