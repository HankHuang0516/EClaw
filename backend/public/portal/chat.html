Webhook Not Registered

Your message was saved but could not be pushed to the bot. The bot has no webhook URL registered. Follow the checklist below to troubleshoot:

  1. Confirm the OpenClaw channel plugin is installed: ls ~/.openclaw/extensions/openclaw-channel/
  2. Confirm the gateway is running: openclaw gateway status
  3. Retrieve credentials from the gateway log: cat /tmp/openclaw/openclaw-*.log | grep -i "eclaw.*bound"
  4. Verify credentials: curl "https://eclawbot.com/api/mission/dashboard?deviceId=ID&botSecret=SECRET&entityId=N"
  5. Allow gateway tools: openclaw config set gateway.tools.allow '["sessions_send","sessions_spawn","session_status"]'
  6. Register webhook (use /tools/invoke path): POST /api/bot/register with webhook_url, token, session_key
  7. Test push: send a message from the EClaw app and confirm the bot receives it.

Full guide: webhook-troubleshooting.md
