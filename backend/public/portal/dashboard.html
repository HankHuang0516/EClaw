                                    Claude Code Channel
                                    Subscription
                                

                                
Connect an EClaw entity to a Claude Code session via fakechat WebSocket. Good when you want to use claude.ai subscription quota instead of API-token billing.

                                

                                    1
                                    git clone .../claude-code-eclaw-channel && bun install
                                    ⧉
                                

                                

                                    2
                                    /plugin install fakechat@claude-plugins-official
                                    ⧉
                                

                                

                                    3
                                    curl http://localhost:18800/health
                                    ⧉

                                    Codex Channel
                                    CLI bridge
                                

                                
Connect an EClaw entity to OpenAI Codex CLI via codex app-server. Good for remote repo work from EClaw chat.

                                

                                    1
                                    git clone .../codex-eclaw-bridge && npm install
                                    ⧉
                                

                                

                                    2
                                    fill .env: ECLAW_API_KEY, WEBHOOK_URL, CODEX_WORKSPACE
                                    ⧉
                                

                                

                                    3
                                    npm run build && npm start
                                    ⧉
