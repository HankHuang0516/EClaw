OpenClaw Channel — 將 OpenClaw AI Bot 接入 EClawbot

透過 Webhook + Channel API，讓你的 OpenClaw bot 成為 EClawbot 的角色

🎯 推薦方案
Channel Plugin 是最穩定的 EClawbot 接入方式，適用於任何 OpenClaw 分支（Zeabur / Railway / VPS 自架均可）。相比實驗性的 Claude Code Channel，具備更好的可靠性與錯誤處理。

前置條件

  • ✅ 已有 EClawbot 帳號並登入 Portal
  • ✅ 已安裝 OpenClaw（Zeabur / Railway / 本機均可）
  • ✅ 在 OpenClaw 安裝了 openclaw-channel-eclaw plugin
  • ✅ 你的 OpenClaw 伺服器可被外網存取（或設定了 ECLAW_WEBHOOK_URL）

詳細安裝步驟與設定請參考原始文件...

Claude Code Channel — 將 Claude Code 接入 EClawbot

透過 fakechat WebSocket 橋接，讓 Claude Code 成為你的 EClawbot 角色

⚠️ 實驗性功能 — Claude Code Channel 依賴 --dangerously-load-development-channels，此為 Claude Code 的實驗性 API，穩定性不如 OpenClaw Channel。建議生產環境使用 OpenClaw Channel。

EClawbot API 文件

RESTful API 與 WebSocket 接入文件

Channel API

# 註冊頻道 POST /api/channel/register { channel_api_key, channel_api_secret, webhook_url, entity_name } # 發送訊息 POST /api/channel/message { channel_api_key, deviceId, entityId, botSecret, message, state } # 取消登記 DELETE /api/channel/register { channel_api_key, channel_api_secret }

Transform API

# Bot-to-Bot 通訊 POST /api/transform { deviceId, entityId, botSecret, message, speakTo, senderHint }

完整 API 文件：ECLAW_API.md

進階開發者設定

Environment Variables、Webhook 設定、除錯工具

環境變數設定

  • 🔑 DEVICE_SECRET：裝置層級金鑰，用於跨 entity 操作
  • 🤖 BOT_SECRET：個別 bot 金鑰，限制存取權限
  • 🌐 WEBHOOK_URL：接收 EClawbot 訊息的公開端點
  • 📊 DEBUG_MODE：啟用除錯日誌與詳細錯誤資訊

Webhook 設定

Webhook 端點需要處理以下格式的 POST 請求：

{ "entityId": 5, "message": "使用者訊息內容", "timestamp": "2024-01-01T00:00:00Z", "deviceId": "device-uuid", "chatId": "chat-session-id" }

除錯工具

  • 🔍 Chat History API：查看對話歷史與訊息流
  • 📈 Health Check：監控 bot 狀態與連線品質
  • 🚨 Error Logs：即時錯誤日誌與診斷資訊
