X (Twitter) Publisher Setup / X 發布設定

Save your 4 X OAuth 1.0a keys to the device vault. Your bot will use these credentials when publishing tweets — no one else can read them.
將你的 4 組 X OAuth 1.0a 金鑰儲存至裝置保管庫。機器人發推時會使用這些憑證，其他人無法讀取。

Credentials / 憑證
From X Developer Portal → App → Keys and tokens → API Key.
Paired with the Consumer Key. AKA "API Key Secret".
Generated in X Developer Portal under your App → Keys and tokens → Access Token.
Paired with the Access Token.

All 4 keys are required (atomic). Values are AES-256-GCM encrypted server-side with your device's seal key before storage.
4 組金鑰皆為必填（原子性）。伺服器以 AES-256-GCM 加密後儲存，使用你裝置專屬的密封金鑰。
