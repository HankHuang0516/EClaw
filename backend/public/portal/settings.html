😴 Entity activity & sleep

When your bots show as busy, idle, or sleeping on the wallpaper. The server decides this deterministically — a bot with pending work never sleeps.

Go idle after Seconds after a bot's last message (with no pending work) before it shows as idle.
Go to sleep after Minutes of inactivity (no pending work) before an idle bot falls asleep.
Trust live status for Seconds a bot's self-reported live status (busy / waiting / error) is trusted before the server falls back to timing rules.

How usage warning works

                

                    
When enabled, if Claude 5h remaining ≤ your 5h threshold OR weekly remaining ≤ your 7d threshold, the Agent prepends a system warning to every outgoing message in this device.

                    
    
                        
  • 5h threshold default 15% — warning fires roughly 45min before exhaustion.
    • 
                        
  • 7d threshold default 5% — warning fires roughly 8h before exhaustion.
    • 
                        
  • This does NOT change Agent behavior — it only tells the dialog partner that quota is tight.
    • 
                        
  • When the toggle is OFF, quota-exhaustion failures still occur but with no advance warning.
