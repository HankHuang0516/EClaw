## 已查到的限制

- 正式 OIDC 驗證器只接受已核准的工作流程提交、分支與 `push` 事件，而且初次執行不具寫入權。GitHub 定時工作只從預設分支執行，壅塞時可延遲或略過。重跑既有人工工作也有 30 天與 50 次上限。沿用 GitHub OIDC 發行者可免新增 API 金鑰，排程仍須有獨立且限縮的正式身分綁定。 [GitHub 定時工作](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule) · [重跑限制](https://docs.github.com/en/actions/how-tos/manage-workflow-runs/re-run-workflows-and-jobs)
- King County 將 `azpa-gwmk` 標為 Public Domain。欄位有 `FOUND`、拾獲日或收容登錄日期，也有目前位置欄位。公開 metadata 沒有定義案件仍有效、明確結案或消失的語意。資料集更新時間只能佐證更新，不能佐證個案仍有效。資料缺明確在案證據就留人工確認。 [官方資料集與欄位](https://data.kingcounty.gov/api/views/azpa-gwmk)
- 目前正式條款第 4 條限制一般自動化使用。若要讓這條路徑持續自動送件，先記錄僅限官方專用端點、單一來源與待審的例外。 [正式條款](https://api-production-8bc1.up.railway.app/terms?lang=zh-Hant)

排程測試以測試時鐘及本機 loopback 合成 API 執行。照片端到端使用已有的 `stray-map-release-preflight:3ec76d896` 及 `postgis/postgis:17-3.5` 映像，在本機 Docker Desktop 的隔離網路以 Linux／amd64 執行，沒有外網與主機連接埠。程式用匿名 GET 與固定語言模板。首次完整且獲准的讀取只建立基線。後續新案需有明確 `ACTIVE` 證據、實際拾獲日、可信粗區域及合格照片。明確結案不再受理，資料消失保留為未知。

## 照片契約

1. 每筆至少一張、至多兩張可辨認為本案同一動物的原始照片。原始捕捉與同一動物的對應需由可信授權帳冊確認。AI 圖與只有相似外觀的影像不可受理。
2. 授權須來自原作者或可核實的權利條款。保留作者要求的署名、授權證據、同案來源鍵、原始 bytes SHA-256 和授權修改範圍。驗證器在正式採用時需能核對再發布及必要安全處理的權利。
3. 收件請求的 `photos` 只允許已核對上傳的 `uploadId`、`rights`、`caption`。獨立帳冊驗證來源／資料集／個案／原始影像綁定、身份與位置風險、授權有效、EXIF 及定位已去除。伺服器只處理有界原始 bytes 的私有上傳，任意圖片 URL 一律拒收。顯示位置只保留國別與粗區域，排除人臉、車牌、個資、敏感棲地與可定位影像。
4. 收件端使用自己的可信在案證據，核對個案授權與最近確認時間。缺圖、授權不明、影像不符、辨識風險、在案狀態不明或證據過期都拒收。回執為 `PENDING`、`publicVisible: false`。授權或在案證據在續查時失效，後續不得重送。

隔離帳冊由測試程式用自製像素和合成授權建立，用於驗證資料與授權綁定、實際解碼及去 metadata。真實照片是否同一動物、真實權利人、影像個資與敏感位置的辨識尚未驗證。署名參照留在私有證據，正式公開署名呈現待另驗。

## 正式啟用所需的最小決策

1. 從資料發布方的正式 API 或文件核實個案仍有效及明確結案的判準，並核實分頁與空集合語意。King County 還缺可核對的在案證據，以及至少一筆具原始照片再發布、必要安全處理與署名授權的個案。
2. 核准隔離的照片上傳與待審端點進入正式後端，並將既有免金鑰身分精確綁到這個照片專用用途、單一來源、固定的定時工作。沿用每小時一件與十筆待審上限。現有正式身分只適用原本的文字路徑。待另驗正式照片服務的儲存、撤回、關閉後保留、跨程序排程與 GitHub 延遲。
3. 核准僅涵蓋該單一來源和專用端點的正式排程規則。全球來源由 Dot 自行用公開 API 巡查，來源納入需各自核對授權與在案證據。公開上圖、App 和 Hub 須分開驗收。

## 獨立驗收

- 正式收件先用一筆自然出現且明確仍在案、照片授權完整的紀錄，核對唯一待審回執、尚無公開投影、停用後保留回執。
- Hub 用授權的後端彙總核對待審數、已去重、來源中斷與資料缺口。使用桌面與手機驗證，正式原生通報數和此來源隊列各自核對。
- 聯測版 App 用合成批准案例核對當地語言、概略區域卡片與撤回。現階段待審不得在 App 出現。正式 App 顯示、圖釘和公開上圖須獨立授權後驗。
- 真實照片另驗權利人憑據、同一動物辨認、必要署名和圖片撤回。公開候選另驗粗區域、安全投影及分享網址。
